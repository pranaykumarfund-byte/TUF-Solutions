## 📝 Problem Statement

Given an integer array **nums** , **return** the sum of the **1** ^ **st** and **last** element of the array.

### Example 1

<p>

**Input:** nums = [2, 3, 4, 5, 6]</p><p>

**Output:** 8</p><p>

**Explanation:** 1st element = 2, last element = 6, sum = 2 + 6 = 8.</p>

### Example 2

<p>

**Input:** nums = [2]</p><p>

**Output:** 4</p><p>

**Explanation:** 1st element = last element = 2, sum = 2 + 2 = 4.</p>

### Example 3

Input: nums = [-1, 2, 4, 1]

Output:

0

### Constraints

- 1 <= Number of elements in nums <= 100
- -100 <= nums[i] <= 100
