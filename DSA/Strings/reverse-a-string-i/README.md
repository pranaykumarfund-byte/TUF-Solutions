## 📝 Problem Statement

Given an input string as an array of characters, write a function that **reverses** the string.

### Example 1

<p>

**Input:** s = ["h", "e", "l", "l", "o"]</p><p>

**Output:** ["o", "l", "l", "e", "h"]</p><p>

**Explanation:** The given string is s = "hello" and after reversing it becomes s = "olleh".</p>

### Example 2

<p>

**Input:** s = ["b", "y", "e" ]</p><p>

**Output:** ["e", "y", "b"]</p><p>

**Explanation:** The given string is s = "bye" and after reversing it becomes s = "eyb".</p>

### Constraints

- 1 <= s.length <= 10^3
- s consist of only lowercase and uppercase English characters.

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
