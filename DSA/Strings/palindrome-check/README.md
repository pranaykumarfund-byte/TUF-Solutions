## 📝 Problem Statement

You are given a string **s** . Return **true** if the string is palindrome, otherwise **false** .

A string is called **palindrome** if it reads the same forward and backward.

### Example 1

<p>

**Input:** s = "hannah"</p><p>

**Output:** true</p><p>

**Explanation:** </p>The given string when read backward is -> "hannah", which is same as when read forward.

Hence answer is true.

### Example 2

<p>

**Input:** s = "aabbaaa"</p><p>

**Output:** false</p><p>

**Explanation:** </p>The given string when read backward is -> "aaabbaa", which is not same as when read forward.

Hence answer is false.

### Constraints

- 1 <= s.length <= 10^5
- s consist of only uppercase and lowercase English characters.

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
