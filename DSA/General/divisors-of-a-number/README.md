## 📝 Problem Statement

You are given an integer **n** . You need to find **all** the **divisors** of n. Return all the **divisors** of **n** as an array or list in a sorted order.

A number which completely **divides** another number is called it's **divisor** .

### Example 1

<p>

**Input:** n = 6</p><p>

**Output:** = [1, 2, 3, 6]</p><p>

**Explanation:** The divisors of 6 are 1, 2, 3, 6.</p>

### Example 2

<p>

**Input:** n = 8</p><p>

**Output:** [1, 2, 4, 8]</p><p>

**Explanation:** The divisors of 8 are 1, 2, 4, 8.</p>

### Constraints

- 1 <= n <= 1000
