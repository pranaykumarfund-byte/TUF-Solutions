## 📝 Problem Statement

You are given an integer **n** . You need to check if the number is **prime** or not. Return **true** if it is a **prime** number, otherwise return **false** .

A **prime** number is a number which has **no** divisors except **1** and **itself** .

### Example 1

<p>

**Input:** n = 5</p><p>

**Output:** true</p><p>

**Explanation:** The only divisors of 5 are 1 and 5 , So the number 5 is prime.</p>

### Example 2

<p>

**Input:** n = 8</p><p>

**Output:** false</p><p>

**Explanation:** The divisors of 8 are 1, 2, 4, 8, thus it is not a prime number.</p>

### Constraints

- 1 <= n <= 5000
