## 📝 Problem Statement

Write a function to find the **longest** **common** **prefix** string amongst an array of strings.

If there is no common prefix, return an empty string "".

### Example 1

<p>

**Input:** str = ["flowers" , "flow" , "fly", "flight" ]</p><p>

**Output:** "fl"</p><p>

**Explanation:** </p>All strings given in array contains common prefix "fl".

### Example 2

<p>

**Input:** str = ["dog" , "cat" , "animal", "monkey" ]</p><p>

**Output:** ""</p><p>

**Explanation:** </p>There is no common prefix among the given strings in array.

### Example 3

<p>

**Input:** str = ["lady" , "lazy"]</p>Output:

la

### Constraints

- 1 <= str.length <= 200
- 1 <= str[i].length <= 200
- str[i] contains only lowercase English letters.

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
