## 📝 Problem Statement

You are given an integer **n** . Return the **largest digit** present in the number.

### Example 1

<p>

**Input:** n = 25</p><p>

**Output:** 5</p><p>

**Explanation:** The largest digit in 25 is 5.</p>

### Example 2

<p>

**Input:** n = 99</p><p>

**Output:** 9</p><p>

**Explanation:** The largest digit in 99 is 9.</p>

### Constraints

- 0 <= n <= 5000
- n will contain no leading zeroes except when it is 0 itself.

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
