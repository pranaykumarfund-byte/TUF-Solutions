## 📝 Problem Statement

Given an integer **age** , print on the screen:

- **Adult** if **age** >= 18
- **Teen** if **age** < 18

Do **not** **change** the case of any letter in "Adult" and "Teen" while printing the answer.

**For printing use:-**

- for **C++** : cout << variable_name<<endl;
- for **Java** : System.out.println();
- for **Python** : print()
- for **Javascript** : console.log()

### Example 1

<p>

**Input:** age = 19</p><p>

**Output:** Adult</p><p>

**Explanation:** age is greater than or equal to 18.</p>

### Example 2

<p>

**Input:** age = 7</p><p>

**Output:** Teen</p><p>

**Explanation:** age is less than 18.</p>

### Example 3

<p>

**Input:** age = 18</p>Output:

Adult

### Constraints

- 0 <= age <= 100
