## 📝 Problem Statement

Given **marks** of a student, **print** on the screen:

- **Grade A** if marks >= 90
- **Grade B** if marks >= 70
- **Grade C** if marks >= 50
- **Grade D** if marks >= 35
- **Fail** , otherwise.

**For printing use:-**

- for **C++** : cout << variable_name;
- for **Java** : System.out.print();
- for **Python** : print()
- for **Javascript** : console.log()
- for **C#** : Console.WriteLine();
- for **Go** : fmt.Println()

### Example 1

<p>

**Input:** marks = 95</p><p>

**Output:** Grade A</p><p>

**Explanation:** marks are greater than or equal to 90.</p>

### Example 2

<p>

**Input:** marks = 14</p><p>

**Output:** Fail</p><p>

**Explanation:** marks are less than 35.</p>

### Example 3

<p>

**Input:** marks = 70</p>Output:

Grade B

### Constraints

- 0 <= marks <= 100
