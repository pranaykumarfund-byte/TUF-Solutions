## 📝 Problem Statement

You are given an integer **n** . You need to find out the **number** of **prime** numbers in the range **[1, n]** (inclusive). Return the **number** of **prime** numbers in the range.

A **prime** number is a number which has **no** divisors except, **1** and **itself** .

### Example 1

<p>

**Input:** n = 6</p><p>

**Output:** 3</p><p>

**Explanation:** Prime numbers in the range [1, 6] are 2, 3, 5.</p>

### Example 2

<p>

**Input:** n = 10</p><p>

**Output:** 4</p><p>

**Explanation:** Prime numbers in the range [1, 10] are 2, 3, 5, 7.</p>

### Constraints

- 2 <= n <= 1000

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
